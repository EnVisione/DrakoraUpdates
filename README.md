# Drakora updates

Public release metadata for the Drakora player mod on Minecraft 1.20.1. Player mod source remains private. Internal staff mods are not distributed here.

`updates.json` lists published, verified player downloads for Forge and Fabric. An empty release list means no update is advertised. Each release includes its loader, Minecraft version, mod version, filename, byte size, SHA-256 checksum, download URL, and CurseForge file page.

Only advertise a release after its download and CurseForge page are available. The client checks metadata while connected to the verified Drakora network, verifies downloaded files, and provides a CurseForge fallback if a download fails. Downloaded files must be installed with Minecraft closed.
